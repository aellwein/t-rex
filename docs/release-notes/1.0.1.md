# t-rex 1.0.1

A fix release. The application is unchanged from 1.0.0.

## Fixed

- The Helm chart uses a PNG logo, so Artifact Hub shows the icon. The logo is a stylized T-rex.
- The web app's favicon is the original icon file again.

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.1 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.0 with `helm upgrade`. No values change.
