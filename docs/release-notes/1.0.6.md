# t-rex 1.0.6

A maintenance release. The application behaves as in 1.0.5.

## Changed

- Dependencies are updated: `url` and `pretty_env_logger` in the server, `vergen-gitcl` in the server build, and `toml` in the command line client.
- The container runtime image is updated to the current distroless static image (Debian 13).
- The CI pipeline uses a newer `taiki-e/install-action`.

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.6 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.5 with `helm upgrade`. No values change.
