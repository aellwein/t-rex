# t-rex 1.0.4

A documentation release. The server behaves as in 1.0.3.

## Changed

- The code is documented: module and item docs in all crates, and examples in the API, configuration and development guides. The examples of the shared `dto` crate run as tests.
- The command line client shows times as `hh:mm`. Its `entry list` is paged (`--limit`, `--offset`, `--all`) and takes `--format` for a table, JSON or a template. The client is built from the repository and is not part of the image or the chart.

## Fixed

- The README links the Artifact Hub badge to the repository's package page.

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.4 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.3 with `helm upgrade`. No values change.
