# t-rex 1.0.0

The first stable release of t-rex, a time recording app. Track the time you spend on projects and your absences, day by day, in the web app, from the command line or through the REST API.

## Highlights

- **Web app**: responsive single page app for recording working time per project, absences, and daily hours.
- **Command line client** `t-rex`: the same features as the web app, with browser sign-in, personal tokens and shell completion.
- **REST API** under `/api/v1`, with OpenID Connect sign-in.
- **Storage**: SQLite for a single server, or Postgres.
- **Kubernetes**: Helm chart and multi-architecture container image (linux/amd64, linux/arm64).

## Install

Container image:

```sh
docker pull ghcr.io/aellwein/t-rex:1.0.0
```

Helm chart:

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.0 -f my-values.yaml
```

The chart is signed with GPG. See [chart/README.md](chart/README.md) for the values and the [configuration](docs/configuration.md) for the server settings.
