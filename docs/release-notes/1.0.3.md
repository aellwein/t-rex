# t-rex 1.0.3

A feature release. The REST API and the stored data are unchanged.

## Added

- Reports: a month detail view. For the selected month it lists every booking day by day, with time, project or absence, duration, break and note, and a summary per day. The month ends with the target, the actual time and the difference, and the totals per project and absence kind. Export as PDF works as in the other views.

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.3 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.2 with `helm upgrade`. No values change.
