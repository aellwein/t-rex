# t-rex 1.0.5

A maintenance release. The application behaves as in 1.0.4 apart from the fix below.

## Fixed

- The colour themes no longer list Nord twice. Nord is offered as Nord Light and Nord Dark, as before.

## Changed

- Dependencies are updated: `rand` in the server, `gloo-net` in the web app, and `clap` and `clap_complete` in the command line client.

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.5 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.4 with `helm upgrade`. No values change.
