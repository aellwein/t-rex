# t-rex 1.0.2

A fix release. The application changes only in how long a browser sign-in lasts.

## Fixed

- A browser sign-in lasts 12 hours without activity. Before, the session cookie expired after 30 minutes while the server-side session lasted one hour. Open browser tabs were signed out early and showed "sign in required".

## Install

```sh
helm install t-rex oci://ghcr.io/aellwein/t-rex/t-rex --version 1.0.2 -f my-values.yaml
```

## Upgrade notes

Upgrade from 1.0.1 with `helm upgrade`. No values change. Users who are signed in keep their session until it expires under the new lifetime.
